## About

I build systems at the intersection of **Computer Vision, Applied AI, and Software Engineering** — from training and evaluating models to shipping the APIs, dashboards, and infrastructure that put them in front of users. My main technical interest is **efficient, real-time object detection** and edge deployment; my day-to-day shipped work is full-stack AI applications (FastAPI + Next.js), local-first AI tooling, and security utilities.

That work is backed by a full-stack engineering background (FastAPI, Laravel, Next.js, Flask) and a growing foundation in **Linux systems, networking, IoT, and cybersecurity tooling** — because a model is only useful once it's running inside a real system: an API, a database, a server, a network, a device.

```
MODEL → CODE → API → DATABASE → SERVER → NETWORK → SECURITY → EDGE DEVICE
```

I'm an Informatics Engineering student at **Universitas Muhammadiyah Riau**, currently deepening applied AI research and open-source tooling that connects model development to the systems AI actually runs on.
